# MarkasMerchan Digital Catalog

Saya ingin membangun website resmi untuk brand bernama:

MARKASMERCHAN

IMPORTANT:

Untuk tahap ini, fokus HANYA pada FRONTEND, UI/UX, visual design, layout, responsive behavior, animation, dan user interaction.

JANGAN mengaktifkan atau membuat:

- Lovable Cloud

- Database

- Supabase

- Authentication

- Backend

- API

- CMS

- User login/register

- Payment gateway

- Server-side functionality

Jangan membuat arsitektur backend apa pun.

Website ini untuk tahap pertama adalah STATIC / FRONTEND EXPERIENCE.

==================================================

Website harus benar-benar responsive.

Desktop:

- collage composition

- floating images

- large typography

- generous whitespace

Tablet:

- reduce image overlap

- maintain collage character

Mobile:

- jangan hanya mengecilkan desktop layout

- susun ulang composition

- preserve scrapbook character

- product images tetap prominent

- typography tetap expressive

- navigation menjadi mobile menu

- CTA mudah disentuh

- tidak ada horizontal overflow

Pastikan:

- no horizontal scrolling

- no clipped text

- no overlapping critical content

- buttons touch-friendly
